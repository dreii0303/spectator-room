Scoring

Each completed round is worth 25 points.

Complete five rounds in one run for a +50 point clean-memory bonus.

The sequence keeps growing, so every round is worth the same but much harder to reach.

How to play

Press Start Run. Four pads will light up in order. When the board unlocks, click or tap them in the same order.

Repeat the full sequence to advance. The next pattern adds one step. A single wrong pad ends the run.

Each pad has its own tone, so you can play it by ear as well as by sight.

Play money only. No real gambling.
